# Welcome to Grav

This is the first example blog post. It lives at
`user/pages/04.blog/_sample-post/default.md`.

Grav pages are just folders containing a Markdown file. The leading
underscore (`_`) in the folder name hides the page from the menu while
still making it routable, which is handy for blog posts listed by a
parent index.

## Why Grav?

- **File-based** — no database, content lives in plain text you can
  version-control.
- **Fast** — built on Symfony 7 + Twig 3 with aggressive caching.
- **Flexible** — themes and plugins are plain PHP; page templates are
  Twig.

> [!IMPORTANT]
> This example uses the minimal "Core + Admin" package, not a full blog
  skeleton. If you want a production blog, grab the Blog Site skeleton
  from the [Grav downloads page](https://getgrav.org/downloads).

See the [About page](../03.about) for details about this local test
setup.
